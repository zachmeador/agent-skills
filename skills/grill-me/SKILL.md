# Grill Me

Interview the user relentlessly about every aspect of the plan until reaching shared
understanding. Walk down each branch of the decision tree, resolving dependencies between
decisions one by one. For each question, provide a recommended answer.

Ask one question at a time.

If a question can be answered by exploring the codebase, explore the codebase instead.
